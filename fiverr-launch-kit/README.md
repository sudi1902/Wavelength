# Fiverr AI-Video Service — Launch Kit

Everything needed to go live is in this folder. The AI pipeline (Higgsfield), portfolio samples, and all copy are done. What remains is the ~30 minutes of account work only a human can do.

## What's in here

| Path | What it is |
|---|---|
| `portfolio/` | 3 finished 1080p 9:16 ad samples + 3 hero images (gig gallery assets) |
| `gig/fiverr-gig.md` | Title, tags, 3-tier pricing, description, FAQ, requirements form — paste-ready |
| `gig/upwork-catalog.md` | Upwork Project Catalog duplicate listing |
| `outreach/reddit-replies.md` | 10-reply demand-hunting playbook + templates |
| `outreach/upwork-proposals.md` | 3 proposal templates for active job posts |
| `ops/delivery-sop.md` | Per-order fulfillment workflow (≤45 min/order) + credit economics |

## Go-live checklist (do in this order)

**Now (~30 min):**
1. [ ] Fiverr: create/log into seller account → New Gig → paste everything from `gig/fiverr-gig.md`. Upload the skincare video as the gig video, other two videos + 3 images into the gallery. Publish.
2. [ ] Set Fiverr availability + enable mobile app notifications (response time is a ranking factor; answer every message within the hour).
3. [ ] Upwork: create Project Catalog listing from `gig/upwork-catalog.md` (approval can take ~24h — start it now so it clears while Fiverr warms up).

**Today (hour 5–6):**
4. [ ] Fiverr "Get Briefs": turn ON in seller dashboard (Briefs replaced the old Buyer Requests — buyers describe needs, Fiverr matches sellers; answer every relevant brief same-hour).
5. [ ] Reddit/X sweep per `outreach/reddit-replies.md` — 10 genuinely helpful replies to people actively asking for video help. This is the highest-probability source of a same-day first order.
6. [ ] Upwork: spend free Connects on <24h-old job posts per `outreach/upwork-proposals.md`.

**When the first order lands:**
7. [ ] Follow `ops/delivery-sop.md`. Over-deliver on orders 1–5 (free extra variation). Ask for a review in the delivery message.

## Honest expectations
- Live and positioned in front of demand: today. First dollar: possibly hour 5, more likely day 1–3. The manual outreach (step 5) is what pulls it earlier.
- After 5 reviews: raise Basic $25 → $45, keep response time <1h, add a "beauty brands" niche gig as gig #2 (niche gigs rank).
